# رَوَند

اپلیکیشن Flutter تحلیل بازار خودرو با رابط فارسی RTL. اپ مستقیماً به وب‌سرویس
SourceArena متصل می‌شود و هیچ بک‌اند اختصاصی ندارد.

## امکانات

- نبض روز بازار و بیشترین رشد/افت
- جست‌وجو، فیلتر و مرتب‌سازی خودروها
- نمودار تغییر قیمت و جزئیات هر خودرو
- مقایسه هم‌زمان دو خودرو
- رتبه‌بندی بازده در بازه‌های زمانی
- پیشنهاد خودرو بر اساس بودجه
- محاسبه سناریوی «اگر خریده بودم»
- کش محلی، حالت آفلاین و دیتاست نمایشی
- رابط Material 3، حالت روشن/تیره و طراحی واکنش‌گرا

## اجرای متصل به API

توکن در سورس ذخیره نمی‌شود. آن را هنگام اجرا تزریق کنید:

```bash
flutter run --dart-define=SOURCEARENA_TOKEN=YOUR_TOKEN
```

ساخت خروجی‌ها:

```bash
flutter build apk --release --dart-define=SOURCEARENA_TOKEN=YOUR_TOKEN
flutter build web --release --dart-define=SOURCEARENA_TOKEN=YOUR_TOKEN
```

همچنین می‌توان در حالت نمایشی، روی نشان «حالت نمایشی» در هدر زد و توکن را
در خود اپ وارد کرد. مقدار واردشده فقط در فضای محلی همان نصب ذخیره می‌شود.
توکن واردشده فقط پس از دریافت موفق داده ذخیره خواهد شد؛ اگر اتصال ناموفق باشد،
توکن سالم قبلی حفظ می‌شود.

## پیش‌نمایش Web

پس از ساخت Web، روی macOS فایل زیر را اجرا کنید:

```bash
./serve_preview.command
```

روی Windows فایل `serve_preview.bat` را دوبار کلیک کنید، یا در CMD اجرا کنید:

```bat
cd /d "C:\path\to\ravand"
serve_preview.bat
```

پیش‌نمایش در `http://127.0.0.1:41828` باز می‌شود. سرور همراه پروژه برای جلوگیری
از اجرای JavaScript قدیمی، پاسخ‌ها را با هدرهای بدون‌کش ارائه می‌کند.

## نکات امنیتی

در اپ کاملاً client-side هیچ راهی برای مخفی‌کردن واقعی توکن وجود ندارد؛ توکن
کامپایل‌شده از APK یا فایل JavaScript قابل استخراج است. خروجی متصل را عمومی
منتشر نکنید مگر اینکه ریسک مصرف سهمیه و افشای توکن را پذیرفته باشید. برای محصول
عمومی، راه امن استفاده از یک proxy کوچک با rate limit و محدودیت دامنه/کاربر است.

نسخه Web علاوه بر این، به فعال بودن CORS در SourceArena وابسته است. Android و
iOS محدودیت CORS مرورگر را ندارند.

اگر درخواست در PowerShell یا اپ Android موفق است ولی فقط در Web شکست می‌خورد،
تنظیم CORS سرویس را بررسی کنید. خطاهای انقضای توکن، اتمام سهمیه، اختلال سرویس
و timeout در رابط اپ به‌صورت جداگانه نمایش داده می‌شوند.

## ساختار اصلی

```text
lib/core/      قالب‌بندی فارسی و دیزاین‌سیستم

lib/state/     وضعیت و منطق تحلیل
lib/ui/        صفحات و کامپوننت‌های رابط
```
